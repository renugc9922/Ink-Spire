## ✨ About

**Ink-Spire** is an AI-powered storytelling platform designed to make creative writing more interactive and collaborative.

The platform assists users in developing stories, generating ideas, continuing narratives, and exploring creative possibilities with the help of AI.

It combines a modern web interface with AI-powered storytelling capabilities to create an engaging writing experience.

---

## 🚀 Key Features

* 🤖 **AI-Assisted Storytelling** — Generate and develop story content with AI
* ✍️ **Interactive Writing** — Build and continue narratives dynamically
* 💡 **Creative Assistance** — Explore ideas, characters, and story directions
* 📖 **Narrative Development** — Maintain continuity while developing stories
* 🎨 **Modern UI** — Clean and responsive interface for an immersive writing experience
* 📱 **Responsive Design** — Works across desktop, tablet, and mobile devices

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

* **Node.js**
* **npm**
* **Git**

### Clone the Repository

```bash
git clone <repository-url>
cd Ink-Spire
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

Open another terminal:

```bash
cd backend
npm install
npm start
```

> Environment variables may be required depending on the AI services and backend configuration. Refer to `.env.example` for the required configuration.
